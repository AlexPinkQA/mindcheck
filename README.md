# MindCheck 🧠

**MindCheck** — це відкрита, безкоштовна та конфіденційна платформа для клінічного первинного скринінгу психоемоційного стану людини.

> ⚠️ **Важливе застереження**: MindCheck є інструментом психологічного скринінгу та самоусвідомлення, а не медичним діагнозом.

---

## 🌟 Ключові особливості

1. **Zero-Data / Local-First**:
   * Жодних акаунтів, реєстрацій чи збору персональних даних.
   * Відповіді обробляються виключно в пам'яті браузера (або зберігаються в `localStorage` як чернетка) і **ніколи не передаються на сервер**.

2. **Ступінчасте (адаптивне) оцінювання**:
   * **Етап 1 (3–5 хв)**: Валідована шкала **PHQ-9** для первинного визначення рівня депресивних симптомів.
   * **Етап 2 (+10 хв)**: Поглиблений аналіз тривожності (**GAD**), соматичних проявів, тривалості та впливу на життя.

3. **Кризовий протокол безпеки (Crisis Intervention)**:
   * Негайне реагування на тригери самопошкодження.
   * Актуальні контакти гарячих ліній та **текстових чатів підтримки для підлітків та молоді** (Lifeline Ukraine 7333, Teenergizer, Ла Страда, 988 тощо).

4. **Практична користь (Actionable Report)**:
   * Можливість в 1 клік скопіювати структуроване зведення симптомів для візиту до психотерапевта або психіатра.

5. **$0 / місяць на підтримку**:
   * Повністю статичний клієнтський додаток без платних серверів, баз даних чи AI-токенів. Працює як PWA.

## 🛠 Технологічний стек

* **Frontend**: React 19, TypeScript
* **Збірка**: Vite
* **Стилі**: Tailwind CSS
* **Іконки**: Lucide React

---

## 🚀 Швидкий старт локально

```bash
# 1. Встановлення залежностей
npm install

# 2. Запуск локального dev-сервера
npm run dev

# 3. Збірка для продакшну
npm run build
```
